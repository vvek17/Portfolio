# Portfolio

Personal portfolio website by Vivek Solanki — built to showcase my projects, skills, and background in data science and machine learning.

Live site: https://portfolio-phi-dun-85.vercel.app/

## Tech Stack

- Framework: Next.js (App Router)
- Language: TypeScript
- Styling: Tailwind CSS, SCSS
- UI Components: shadcn/ui
- Font: Geist (via next/font)
- Deployment: Vercel

## Features

- Responsive, mobile-first design
- Sections for About, Projects, Skills, and Contact
- Clean, component-driven architecture
- Fast load times with Next.js optimization

## Getting Started

Clone the repo and install dependencies:

```bash
git clone https://github.com/vvek17/Portfolio.git
cd Portfolio
npm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

## Project Structure

```
├── app/          # App Router pages and layouts
├── components/   # Reusable UI components
├── lib/          # Utilities and helpers
└── public/       # Static assets
```
